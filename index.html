Privacidade & Segurança

Seus dados ficam no seu navegador

Sem servidor externo, sem coleta de dados em nuvem. O que você registra permanece no seu dispositivo.

100% local

Usamos localStorage do seu navegador. Os dados não saem do seu computador/celular.

Autenticação simulada

O login/cadastro é didático (apenas para separar contas). Em um app real, senhas seriam tratadas com segurança no servidor.

Sem rastreamento

Não usamos analytics, cookies de terceiros ou ferramentas de rastreamento. Seu uso é privado por padrão.

FAQ

Perguntas frequentes

As dúvidas mais comuns, respondidas de forma simples.

Os meus dados vão para a nuvem?

Não. Tudo é salvo no localStorage do seu navegador. Os dados ficam no seu dispositivo.

O login/cadastro é seguro de verdade?

É uma simulação didática. Não usa servidor nem criptografia forte. Serve para aprender o fluxo, não para guardar senhas sensíveis.

Funciona no celular?

Sim. O site é responsivo e funciona bem em navegadores mobile (Chrome, Edge, Safari).

O que é o Assistente IA no PRO?

Uma sugestão de recurso futuro: um assistente para ajudar na organização financeira (análises simples e dicas), pensado para manter tudo leve e útil.

Preciso instalar alguma coisa?

Não. É só abrir o site no navegador. Funciona abrindo os arquivos localmente ou hospedado.
